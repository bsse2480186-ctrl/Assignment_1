# SCD React

Small React + Vite project styled with Bootstrap. It covers components, props, useState, routing and form handling.

## Run it

```
npm install
npm run dev
```

## Folder layout

- `src/components` has the Navbar, Footer, Breadcrumb, Button, Card and the pages (Home, About, Contact)
- `src/App.jsx` only holds the routes and connects the components
